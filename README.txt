BERLING - Tienda de ropa urbana
================================

Estos son los archivos principales:
- index.html       -> Inicio
- catalogo.html    -> Catálogo
- producto.html    -> Detalle de producto
- carrito.html     -> Carrito con contador y cantidades
- login.html       -> Inicio de sesión
- registro.html    -> Registro
- perfil.html      -> Perfil e historial de pedidos
- admin.html       -> Panel administrador
- css/style.css    -> Todos los estilos
- js/script.js     -> Funciones simples del carrito y menú responsive
